# 选人初始化与本机输入隔离修复验证

日期：2026-11-10（Asia/Shanghai）。基于 `4fed9d9` / Online Friends 6.8.1，本报告记录 6.8.2 打包前的修复验证；打包仅另更新版本元数据与发布说明。

## 修改范围

仅修改 Online 的三个生产脚本：

- `scripts/online_player_slot_manager.gd`：客户端选人初始化清空阵容时，延后到当前调用结束后恢复权威阵容，重新通知界面与 FocusEmulator，并重放显示状态。排队回调检查场景实例、会话和阵容锁，防止影响已经切换的场景。正常的重复状态仍保留去重。
- 同一脚本：移除会同时响应本机键盘和第一个手柄的远程占位设备 `0`。安全占位编号不足时拒绝分配；客户端重建中途失败时保留原阵容，避免跳过玩家后压缩编号。没有扩大原版的输入编号空间。
- `scripts/menu_sync_manager.gd`：选人、武器页持续按本机席位配置输入权限；初始化恢复后重放缓存的权威显示并恢复本地焦点。
- `extensions/focus_emulator_safe_disconnect.gd`：在真正处理输入的虚方法中阻止远程席位响应或吞掉本机事件，覆盖新界面还没完成周期配置的窗口。离线场景沿用原版路径。

没有修改 FiveItemShop、NoobsWantToLive、设备热插拔、设备编号重排、战斗快照或网络协议。没有针对用户第 1 项的 A 键硬件故障作推测性修复，也没有修改未定位的确认状态回退逻辑。

## 环境与测试边界

- 恢复的游戏工程，游戏运行器 `Brotato-source.exe`，引擎标识 `3.7.dev.custom_build.74e86be54`。
- Online 当前源码；FiveItemShop **1.1.3**、NoobsWantToLive **1.1.0** 的原始发布包脚本。
- 使用隔离项目 `E:/github/BrotatoMod/work/friends-input-diagnosis-20261110`，每次运行独立用户目录，禁止保存。
- `Local-InputProbe` 是测试工具，只阻止创建 Steam 房间，使多个本机进程使用真正的 ENet/LAN。它不替换玩家槽位、输入、菜单或传输处理。
- 控制器连接通过引擎 `Input.joy_connection_changed` 模拟；确认和方向输入通过 `Input.parse_input_event` 注入。追加本地玩家使用原版长按加入计时器。
- LAN 测试直接将焦点定位到已知角色/武器，随后注入确认键；没有用测试代码直接替玩家确认，也没有手动调用本次新增的修复方法。
- 单进程测试的会话与阵容是受控设置；它验证原版 UI 输入组件，不冒充完整网络流程。

## 原始 6.8.1 对照与失败保留

将隔离项目的生产脚本还原为原始 ZIP，测试脚本保持当时相同版本，使用 `-BaselineArchive` 验证发布包校验值后运行：

- `selection-single-20261110-115444`：原来的 171 条单项断言版本失败，覆盖远程输入未隔离、设备 0 别名导致 P2 确认错误、安全占位耗尽和阵容不完整提交。最终测试在此基础上增加了 8 条方向输入断言。
- `selection-three-20261110-115459`：复现两个客户端加入时列表隐藏和多余加入空框；最后一个客户端无法完成角色确认，最终超时。原始日志与 JSON 均保留。

开发过程中的失败运行也保留。初版输入入口拦截未覆盖继承通知，后改为处理输入的虚方法；初版离线测试未关闭受控会话标志、方向键事件缺少物理键码，均已修正测试设置。一次双手柄回归在所有武器已确认后，因固定两秒等待过早判定客户端尚未切页而失败（`selection-pads-20261110-115853`）；最终改成等待实际场景状态，并在看门狗时限内完成。

最终运行没有 `SCRIPT ERROR`。日志仍包含 Steam 未初始化、初始日志文件缺失、部分 LAN 标识转数值以及退出资源清理消息；这些不计为本次输入断言的通过证明，也未作为本次修复范围。对端完成测试退出后，另一端可能记录发送失败/断连。
